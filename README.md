# Table C-alc

High school grouped data thing calculator in C language, let computer calculate it for you!

# What is Table C-alc?

A basic grouped data calculator in C language, it can count Xi and Xi.Fi for you, as well as total Xi.Fi . 

Just input how many entries and it will adjust it for you. It is basically a shortcut compared to manually counting it one by one and reduce errors!

# Technology Used

Technology used are Embacedero Dev C++ as IDE, and using for loop, arrays, and functions.

# How To Run

Download source, extract, and run the .exe

Or click on release tab, then download the .exe

This program is Windows only
